Agents

Agents that ask before they act

An agent is a declaration first: what it may do, to which pages, on what budget. The model chooses the next step; the declaration decides whether it happens.

See a real run Read the agent docs

From idea to a run you can trust

  1. Declare

    Pick an archetype (retrieval, task, copilot, autonomous) and narrow it: the capabilities it holds, the pages it may touch, and its budget in steps, tool calls and time.

  2. Mark what asks first

    Any capability can be ask-first. When the agent reaches for it, the run stops and keeps everything it has done so far.

  3. Try it

    Walk the declaration with no model at all, or run it with yours: local, hosted, or through the model gateway.

  4. Approve or decline

    A person sees the exact call. Approving performs that stored call, never a new one, and it still passes the gate against today's declaration.

  5. Replay

    Every run is kept, step by step. Run it again from any step as a new run, to see what a different answer would have done.

The declaration

What it may do is data you can review

A declaration is a short file, shown as a map: capabilities, the pages they reach, the budget, and what asks first. It can be diffed, reviewed and checked like any other change.

Only a person can declare, change or withdraw one. An agent, or a model talking to Quilzo over MCP, cannot.

Questions about agents

How do I approve an agent's action?

Open the run on the Agents screen and read what it wants to do, field by field. Let it go ahead, or decline it. From a terminal, quilzo agent approve RUN STEP does the same.

Can a model change what an agent may do?

No. Only a person can declare, change or withdraw an agent. A model chooses among the capabilities the declaration lists, and every action is checked against it.

What if an agent reads a page with hidden instructions?

It can still only do what it declared. Quilzo also notes that the run read stored content, and anything it produced then needs a person before it is relied on.

What comes with every agent

Budgets

Steps, tool calls and minutes. A run that reaches one stops and says which.

Kept runs

Every step and observation, readable later, and resumable if a run was cut off.

Probe

Ask the gate whether an agent would be allowed to do something, without running it.

Any model

Local through Ollama or llama.cpp, or hosted, through one gateway with budgets.

Agents as a log source

What agents do flows into the security console, where new kinds of action are flagged.

Agent cards

Published as an A2A agent card, so other systems can find what an agent offers.
