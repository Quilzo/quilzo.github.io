Compliance

Ask first

The model never holds the authority

Most agent frameworks hand a model your tools and a system prompt asking it to behave. Then the model reads a page, an email or a ticket somebody else wrote, and does what it says.

In Quilzo, every action passes one gate that checks it against the agent's declaration. A hijacked agent can still only do what it declared before anybody talked to it, and what you marked ask-first still waits for you.

Questions people ask

What happens when an agent wants to publish?

It stops and asks. A declaration can mark any capability ask-first, and when the agent reaches for it the run pauses: a person sees the exact page and fields it wants to write. Approving performs that stored call, still inside the declaration's limits. Declining refuses it, and the run carries on without it.

Which frameworks does Quilzo map?

Fourteen: NIST SP 800-53, FedRAMP Low, Moderate and High, ISO/IEC 27001, SOC 2, the NIST Cybersecurity Framework, the HIPAA Security Rule, GDPR, CCPA and CPRA, the EU AI Act, NIST AI RMF, ISO/IEC 42001 and the OWASP Top 10 for LLM applications.

Does Quilzo need a database?

No. Quilzo is one binary that keeps its content in a folder on disk, as files named by their contents, so there is no database to install, run or back up separately.

Can I use my own model?

Yes. Quilzo talks to any model that speaks the OpenAI chat-completions protocol: a local one through Ollama, llama.cpp, LM Studio or vLLM, or a hosted one with a key. The model gateway adds routes, fallbacks and budgets.

Is Quilzo free?

Yes. It is open source under AGPL-3.0-or-later. A commercial licence is available for organisations that cannot use the AGPL, and it is the same program.
