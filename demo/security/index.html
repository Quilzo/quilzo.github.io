Security

A security console that watches itself

Logs in, tested detections over them, findings worked into cases, and actions on other tools only when a second person approves.

Read the security docs

Findings

What the detections found, and what to do next

Detections are Sigma-style rules, each with tests and a record of how often it was right. Findings group by person, so a pattern across several tools shows as one story.

Quilzo's own audit log and public site are sources too: repeated failed sign-ins, admin tokens issued, settings weakened, people probing for the admin, and visitors trying to steer the chatbot all become findings.
