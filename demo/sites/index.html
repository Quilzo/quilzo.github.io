Sites

Sites, built from sections

Content is typed, pages are arranged from sections, and nothing publishes that a reader could not use.

Read the site docs

Arrange

A page is a list of sections

Add a section, move it up or down, edit what is in it. Every change is a draft you can roll back, and every field is checked as it is saved.

Two people editing the same page are told so, and neither overwrites the other.

What a page can be made of

Twenty-three kinds of section. This site uses the hero, tabs, split, steps, timeline, features, metrics, logos, quotes, a chatbot question box, a notice, a table, pricing, questions and calls to action.

Tabs

Radio buttons underneath: keyboard and screen reader friendly, no script.

Metrics and charts

Figures, bars and rings drawn in CSS.

Listings

Records from a typed collection, filtered and sorted.

Media

Galleries, carousels and video with captions required.

From draft to live

  1. Draft

    Changes are kept as drafts, with every version.

  2. Check

    Accessibility, contrast, claims and image rights are checked.

  3. Review

    Optionally, a second person approves.

  4. Publish

    One pointer moves. Rolling back moves it back.

Built in

Search

Languages

Translations that know when their source changed.

Feeds and federation

RSS, JSON Feed and ActivityPub.

Forms

Spam-checked, rate-limited, and kept only as long as you set.
