Agents and AI

AI agent control plane
The layer that decides what AI agents may do: identity, policy, budgets, approvals, and an audit trail of every action, enforced outside the model. Quilzo is one, self-hosted.
AI agent
A program in which a model, or the agent's own code, chooses actions toward a goal. In Quilzo every agent has a declaration.
Declaration (manifest)
One JSON document saying what an agent is for, what it may do and read, how far it may go on its own and what one run may spend. The gate enforces it on every action. See Build an agent.
Capability
An operation an agent may use, such as read_page or write_page. A model picks from the declared list and cannot add to it.
Autonomy
propose, draft or publish: what happens to what an agent produces.
Earned autonomy
A model drives an agent at its declared autonomy only after evaluations show it is not steered by planted instructions. See Evaluate agents.
Human in the loop (ask first)
A capability marked ask first stops the run until a person approves the exact call.
Run
One execution of an agent, kept step by step.
Receipt
The records of one run, each with an inclusion proof against a signed log head, checkable by anybody. See Identity and receipts.
Sponsor
The person who answers for an agent. When they leave, the agent stops.
Prompt injection
Text an AI reads that tells it to do something its user did not ask for. Indirect prompt injection hides it in content: a page, an email, a tool result. See Prompt injection in RAG.
Taint
A mark on a run that has read content somebody else could have written. Its output needs a person before it is relied on.
Exfiltration breaker
Stops a run that holds something private and has read somebody else's words from sending anything out without a person.
pass^k
An evaluation case counts only if every one of k runs passed it.
RAG (retrieval-augmented generation)
Answering from retrieved passages rather than from a model's memory. Quilzo's chatbots cite a passage for every sentence.
MCP (Model Context Protocol)
The open protocol AI apps use to call tools. Quilzo is an MCP server and an MCP client. See Connect AI apps.
MCP gateway
A control point between agents and MCP servers that decides each tool call. See The MCP gateway.
Tool pinning
Recording a hash of each approved tool's definition, so a tool the server later redefines is refused.
A2A (Agent2Agent)
The protocol agents use to describe themselves (an agent card) and hand each other tasks. See A2A.
Shadow AI
AI services people or programs use directly, outside the controls you run. See The fleet.
Model (LLM) gateway
Where every model call goes: routes, budgets and the privacy guard. See Models.

Content and access

Store
A directory holding everything Quilzo keeps.
Object
A blob, tree or commit, named by the SHA-256 of its own bytes. Nothing is overwritten.
Commit
A tree of content plus who, when, why and what came before.
Ref
A name pointing at a commit. Publishing moves the live ref.
Draft and live
Where work happens, and what the public site serves.
Environment
A named ref in a promotion sequence, such as staging and production.
Principal
Who somebody, or some agent, is. Policies are written in terms of principals.
Binding
A grant or a deny: this principal, this role, this part of the site.
Token
A credential proving you are a principal. Only its hash is stored.
