Run the rules

quilzo detect pack install    # the rules that ship
quilzo detect test            # every rule against its own fixtures
quilzo detect run
quilzo sigma import ./rules   # bring your own, in the open standard

A new rule can run in a trial ring before it reaches the queue (quilzo detect ring RULE trial). quilzo detect replay runs every rule over the events people have already ruled on, so a change that would have missed something is caught first. Suppressions end on a date.
