Looked for and not found

On the Analytics screen, Looked for and not found lists the addresses people asked for that are not on the site: a link somebody else has wrong, or a page that moved. Beside each is the page it most likely meant, and Redirect it sends it there. Below it, Searches that found nothing lists what readers searched for in their words, with addresses and numbers masked: each is a page somebody could write.

ToRun
List the site's redirectsquilzo redirect list
Send an old address to where its page is nowquilzo redirect add FROM TO [--temporary]
Take one awayquilzo redirect remove FROM

A redirect is served before any page and changes the live site at once, with no draft to review, so it takes whoever may publish. The running site reads a change within a second, with no restart.

Search engines and agents

  • Once the site has an address (site.base_url), every page names its own address with rel=canonical, so the same page reached with a query string or a trailing slash is one page.
  • In a page's editor, under Search engines, Leave this page out of search results marks it noindex and leaves it out of the sitemap. Published first at names the address a page copies, which becomes its canonical address.
  • Every published page has a Markdown copy at /NAME.md, its words in order, for a reader's agent. llms.txt lists them, and each copy names its page as canonical.
  • With site.indexnow on (it is off by default), each publish tells the search engines that take IndexNow which pages changed, and nothing else. The key is served at /KEY.txt. It goes out under the network purpose indexnow, so an offline deployment refuses it (see Settings).
  • Site search scores its results over the pages the visitor may read, so a page they cannot see does not shape how the others rank.
