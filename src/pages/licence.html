The AGPL, which needs nothing from you

The default is AGPL-3.0-or-later, and it is not a trial. You need no permission, no key and no conversation. You may host Quilzo, modify it, charge for it and build a business on it. If you run a modified Quilzo as a service for other people, those people can have the source of what is actually running.

The commercial licence, for those who cannot take AGPL code

It exists for two groups: organisations whose policy forbids AGPL code outright, and vendors embedding Quilzo in a product they will not release under the AGPL. If you are willing to offer your users the source of what you run, the AGPL already permits everything you are likely to want.

There is one Quilzo

No feature is withheld for paying licensees, there is no separate enterprise build, and no code path branches on which licence the operator holds. Single sign-on, SCIM, access control and the audit log are in the free program. The commercial licence changes the terms you hold the software under, not the software.

Contributing

Contributions need a sign-off and a contributor licence agreement, and copyright stays with you. LICENSING.md has the detail and the project's licensing history, and GOVERNANCE.md says how the project is run.

This manual describes the software and carries the same terms.
