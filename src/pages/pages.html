A page is a set of fields; what it looks like is the template's job, so the same page can be a web page, a feed entry and an API response. Every change writes a new object named by its hash, and nothing is overwritten.

Write and change pages

Open a page to edit it, or type an address in New page at on the Pages screen and press Start writing to open the editor on a new one. A page bound to a type gets a form built from the type; any other page gets a form over its own fields. From the command line:

quilzo add returns=returns.json     # stage a page into the draft
quilzo diff                          # what differs from live
quilzo log                           # the history

The editor's preview shows what you type before you save. With the admin's script it follows you a moment after you stop typing; without it, Show in the preview does the same. Nothing is saved until Save to draft. The script also keeps text typed and not saved for the browser tab, so after a reload the editor offers it back with Put them back or Let them go.

Beside the fields, Form on this page shows one of the site's forms at the foot of the page, and None takes it off. Under Search engines, a page can be left out of search results, or name the address it copies in Published first at (see Search engines).

Build a page from sections

ToRun
See what a page can be built fromquilzo section kinds
List a page's sectionsquilzo section list PAGE
Add onequilzo section add PAGE KIND
Reorderquilzo section move PAGE N up
Change what one saysquilzo section set PAGE N path=value
Make a page a reusable block, or a page againquilzo section block PAGE [--off]
Show a block's sections on a pagequilzo section reuse PAGE BLOCK [--at N]
List every block, and the pages that reuse itquilzo section blocks

A block is sections written once and shown on many pages, such as opening hours or a call to action. Change the block and every page that reuses it changes at the next publish. On the Sections screen, Reuse a block adds one to the page, and Make this page a reusable block turns the page into one. A block is never served on its own: it has no address, no place in the sitemap and no search result. A block still reused on a page cannot be deleted; take it off those pages first.

Share this draft

A link shows somebody with no account a page as the draft is now, on the public site. Later changes do not reach it. It ends when it expires or is revoked.

ToOn the screenOr run
Share a page's draft for a day, a week or up to thirty daysMake a link, in the page's editorquilzo share PAGE --days 7
See the linksListed under Share this draftquilzo share list
End one nowRevokequilzo share revoke ID

The link opens an address under /shared/, marked not to be indexed. Making a link takes whoever may publish the page, and revoking one takes whoever may edit it. The link is shown once, when it is made, so copy it then: Quilzo keeps only a digest of its secret.

Working together

ToRun
Claim a page for 30 minutesquilzo lock PAGE --note "..."
Say what is wrong with a pagequilzo note add PAGE "..."
Confirm a page is still rightquilzo checked set PAGE --every 168h
Move a page and everything under itquilzo move OLD NEW --dry-run
Find broken linksquilzo links --broken

Somebody signed in with a credential for part of the site, such as one issued --on /blog, is held to that path in bulk actions, the pages list, notes and links followed inside a preview.
