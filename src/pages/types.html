A type is a flat list of fields. Bind a page or a collection to it and every write must satisfy it, from the admin, the command line, the API and the agent interface, with no way to write around it.

Define a type and bind pages to it

quilzo type example > product.json   # a definition you can edit
quilzo type add product.json
quilzo type bind PAGE product
quilzo type check                     # validate every bound page

Keep records in collections

ToRun
List collectionsquilzo records collections
Queryquilzo records list products --where range=archive
Add onequilzo records add products field=value
Import many in one commitquilzo records import products rows.json
Require a typequilzo type bind-collection products product
