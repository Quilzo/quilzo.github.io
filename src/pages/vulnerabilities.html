This guide moved to Vaigil. Vulnerabilities in your systems, ranked by KEV, EPSS and SSVC, with VEX, SARIF imports, dependency scans and reachability are part of Vaigil, the security team's own tools, which began as this half of Quilzo. Its guide is Vulnerabilities.

Quilzo keeps what it needs to defend itself, and hands the rest of the record to whoever watches it. Quilzo checks its own build: quilzo self check reads the Go vulnerability database for what this binary actually links, offline, and a flaw reachable through one feature turns that feature off. quilzo self update vulndb.zip brings the database up to date on a machine with no network.

Send Vaigil what happens here

Point the stream at Vaigil's feed, and quilzo serve pushes the audit log every fifteen seconds as signed OCSF batches that Vaigil can prove complete and unchanged:

quilzo config set siem.stream.url https://vaigil.example.org/feeds/quilzo
quilzo siem stream key --json > quilzo-stream-keys.json   # give these to Vaigil
quilzo siem stream status

People stay pseudonymous in what is sent unless siem.stream.reveal is set, which takes two administrators. See the audit log, streamed as it is written.
